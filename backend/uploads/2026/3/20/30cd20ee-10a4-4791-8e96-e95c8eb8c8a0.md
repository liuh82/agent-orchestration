# CCDesk v0.2.0 需求规格说明书

**版本：** v0.2.0（基于 Cline 风格重设计）
**日期：** 2026-03-20
**状态：** 待开发
**前置文档：** architecture-v4-chat-ui.md

---

## 1. 项目概述

### 1.1 项目背景
CCDesk 是一个跨平台桌面应用，为 Claude Code CLI 提供可视化操作界面。v0.1.0 采用终端模拟器思路（tmux 分屏），在 Tauri WebView 中交互失效。v0.2.0 参考 Cline (Claude Dev) 界面，改为聊天式交互。

### 1.2 目标用户
- 使用 Claude Code 进行日常开发的开发者
- 偏好 GUI 操作而非纯命令行的用户
- 需要可视化审批工具调用、查看 diff 的用户

### 1.3 技术栈
| 层 | 技术 |
|----|------|
| 桌面框架 | Tauri v2 |
| 前端 | React 18 + TypeScript + Zustand |
| 代码编辑 | Monaco Editor（代码块内） |
| 后端（Rust） | Tauri Commands + tokio |
| 数据库 | SQLite |
| 代码高亮 | highlight.js + react-markdown |
| 构建 | Vite |

## 2. 功能需求

### 2.1 P0 — 核心功能（必须实现）

#### FR-01: 聊天式消息展示
- 用户消息和 AI 回复交替展示
- 用户消息带头像（👤）、AI 回复带头像（🤖）
- 支持 Markdown 渲染（标题、列表、表格、链接）
- 代码块语法高亮 + 复制按钮 + 行号
- 消息列表自动滚动到最新

#### FR-02: 流式输出
- AI 回复逐字显示（打字机效果）
- 流式解析 CC CLI 的 `--output-format stream-json` 输出
- 实时更新 token 计数
- 支持中途停止生成（Escape 或 ⏹ 按钮）

#### FR-03: 底部输入框
- 多行 textarea，最小高度 60px，最大 200px 自适应
- Enter 发送，Shift+Enter 换行
- 空输入时发送按钮禁用
- 发送中显示 ⏹ 停止按钮替代发送按钮

#### FR-04: CC CLI 进程管理
- 启动 Claude Code CLI 进程（`claude --print --output-format stream-json`）
- 支持选择工作目录（项目路径）
- 支持选择模型
- 进程异常退出时显示错误信息

#### FR-05: 工具调用展示
- Read/Write/Edit/Bash/Glob/Grep 等工具调用以折叠块展示
- 显示工具名称、关键参数、执行状态、耗时
- 状态图标：⏳ running / ✅ completed / ❌ error / 🚫 rejected
- 折叠块可展开查看详细输入输出

#### FR-06: 项目选择
- 支持选择本地项目目录作为工作目录
- Toolbar 显示当前项目路径
- 自动读取 Git 分支信息（如项目有 git）

### FR-07: 三栏布局
- 左栏 Sidebar（240px，可折叠 Cmd+B）：会话列表
- 中栏 Chat Area（flex:1）：消息列表 + 输入框
- 右栏 Tool Panel（300px，可折叠 Cmd+Shift+F）：文件树/Diff

---

### 2.2 P1 — 增强功能（重要）

#### FR-08: 工具调用审批（Permission Prompt）
- Write/Edit/Bash 执行前弹出审批弹窗
- Write/Edit 显示 unified diff（绿增红删）
- Bash 显示命令内容 + 工作目录
- 三个操作按钮：Approve / Reject / Edit & Approve
- "Always auto-approve for this session" 复选框
- 按工具类型配置审批策略（always/ask/deny）

#### FR-09: @ 文件引用
- 输入框中输入 `@` 触发文件路径补全
- 补全列表显示项目目录结构（懒加载）
- 选中后 `@src/App.tsx` 高亮显示
- 发送时后端将 `@` 引用替换为文件实际内容

#### FR-10: Diff 预览
- 统一 diff 渲染（绿底新增、红底删除）
- 支持部分编辑后批准
- Diff 旁显示行号

#### FR-11: 会话管理
- 新建/删除/重命名会话
- 按项目 + 时间分组显示
- 会话标题自动从首条用户消息生成
- 当前活跃会话高亮

#### FR-12: 会话持久化
- SQLite 存储消息历史
- 重启应用后消息不丢失
- 消息包含：role、content、toolCalls、timestamp、tokenUsage

#### FR-13: 停止生成
- 点击 ⏹ 按钮或按 Escape
- 向 CC 进程发送中断信号
- 已输出的内容保留

#### FR-14: Auto-accept 配置
- 设置中按工具类型配置审批策略
- 快捷切换：输入框下方显示当前状态
- 配置持久化到 SQLite

---

### 2.3 P2 — 体验优化（锦上添花）

#### FR-15: Token 使用量条
- Toolbar 显示 context window 使用百分比
- 变色规则：< 70% 蓝 / 70-90% 黄 / > 90% 红
- > 90% 时建议使用 /compact

#### FR-16: 消息编辑 + 重新生成
- 用户消息右上角有编辑按钮
- 编辑后 Resubmit：删除该消息及之后所有消息，重新发送

#### FR-17: 对话压缩（Compact）
- `/compact` 命令或 Toolbar 按钮
- 保留最近 N 条完整消息
- 旧消息替换为 LLM 生成的摘要

#### FR-18: 斜杠命令
- `/clear` 清空、`/model` 切换模型、`/compact` 压缩、`/help` 帮助、`/config` 设置、`/cost` 费用统计
- 输入框输入 `/` 触发命令菜单

#### FR-19: 错误重试
- 工具调用失败显示红色错误信息 + Retry 按钮
- 点击 Retry 重新执行该工具调用

#### FR-20: 文件树面板
- 右侧 Tool Panel 的 Files 标签
- 项目文件树（懒加载，目录展开时读取）
- 文件图标按类型区分
- 点击查看文件内容

#### FR-21: Diff 视图
- 右侧 Tool Panel 的 Diff 标签
- 按文件分组显示所有变更
- 每个 diff 旁有 Revert 按钮

#### FR-22: 全局搜索
- Cmd+K 搜索历史会话标题和内容

#### FR-23: 成本估算
- 根据模型 + token 用量显示费用

## 3. 非功能需求

### 3.1 性能
| 指标 | 要求 |
|------|------|
| 消息渲染延迟 | < 16ms（60fps） |
| 流式输出延迟 | < 50ms（感觉实时） |
| 会话列表加载 | < 200ms（100 条内） |
| SQLite 操作 | < 50ms |
| 冷启动 | < 2s |
| 内存占用 | < 200MB（正常使用） |

### 3.2 兼容性
- macOS 12+（Intel + Apple Silicon）
- Linux（Ubuntu 22.04+ / Fedora 38+）
- Windows 10+

### 3.3 可靠性
- CC 进程崩溃不导致应用崩溃
- 数据库损坏自动恢复
- 自动保存消息（每次发送后）
