## Phase 2：CC CLI 集成（2 天）

### 目标
接入 CC CLI 进程，实现真实流式对话。

### 任务清单

#### Day 3：进程管理 + 输出解析
- [ ] **T2.1** streamParser 工具（`utils/streamParser.ts`）
  - 解析 CC `--output-format stream-json` 每行 JSON
  - 事件类型映射：
    - `content_block_delta` → `text_delta`
    - `tool_use` → `tool_start`（Write/Edit/Bash → `permission_request`）
    - `tool_result` → `tool_result`
    - `result` → `result`（含 token usage）
  - 错误处理（JSON 解析失败、断连）
- [ ] **T2.2** Rust 端 ClaudeProcess（`src-tauri/src/core/process.rs`）
  - `start()` — 启动 CC CLI 子进程
  - `send_input()` — 向 stdin 写入用户输入
  - `read_output()` — 从 stdout 逐行读取
  - `stop_generation()` — 发送 Ctrl+C 中断
  - `kill()` — 终止进程
  - Tauri event 发射：`claude-output`（流式输出）、`claude-permission`（审批请求）
- [ ] **T2.3** Tauri Commands
  - `start_claude(project_path, model)` — 启动进程
  - `send_message(text)` — 发送用户输入
  - `stop_claude()` — 停止生成
  - `kill_claude()` — 终止进程

#### Day 4：前端集成 + 工具展示
- [ ] **T2.4** useClaudeCLI hook（`hooks/useClaudeCLI.ts`）
  - 调用 Tauri commands 管理进程
  - 监听 `claude-output` 事件 → parseStreamLine → 更新 chatStore
  - 错误处理（进程崩溃、超时）
- [ ] **T2.5** ToolCallBlock 组件
  - 折叠块 UI：工具名 + 关键参数 + 状态图标 + 耗时
  - 四种状态渲染：running（spinner）/ completed（✅）/ error（❌ + 错误信息）/ rejected（🚫）
  - 点击展开：显示完整 input + output
  - 动画过渡
- [ ] **T2.6** AssistantContent 组件
  - 组合 MarkdownRenderer + ToolCallBlock
  - 按流式事件顺序渲染
  - 正在生成时显示闪烁光标
- [ ] **T2.7** 接入真实 CC CLI
  - `useChatStore.sendMessage()` 改为调用 Tauri command
  - 流式输出驱动 UI 更新
  - 停止按钮 → `stop_claude()` command
  - 进程状态错误提示

### 验收标准
- [ ] 选择项目目录 → 启动 CC → 输入问题 → 看到流式 AI 回复
- [ ] 工具调用以折叠块展示，状态实时更新
- [ ] ⏹ 按钮可停止生成
- [ ] 进程异常退出显示错误提示

## Phase 3：审批机制 ★（1.5 天）

### 目标
实现工具调用审批弹窗，这是核心交互功能。

### 任务清单

#### Day 5
- [ ] **T3.1** Rust 端审批通道
  - `ClaudeProcess` 遇到 Write/Edit/Bash tool_use → 暂停 stdin 写入
  - 发射 `claude-permission` Tauri event（含 tool name + input）
  - 新增 Tauri command `resolve_permission(decision)` — 恢复/终止
  - decision 类型：Approve / Reject / Edit(String)
- [ ] **T3.2** PermissionPrompt 组件
  - 弹窗 UI（居中，max-width 600px）
  - 显示工具名称和目标文件/命令
  - Write/Edit：渲染 unified diff
  - Bash：显示命令内容 + 工作目录
  - 三个按钮：Approve / Reject / Edit & Approve
  - "Always auto-approve for this session" 复选框
  - Edit & Approve → 内联编辑器修改内容后提交
- [ ] **T3.3** diffParser 工具（`utils/diffParser.ts`）
  - 生成 unified diff（对比原始内容 vs 新内容）
  - 解析 diff 字符串 → `{type: 'add'|'del'|'context', content, lineNum}`
  - Diff 高亮渲染（绿底新增、红底删除、灰底上下文）
- [ ] **T3.4** usePermissionStore（Zustand）
  - `pendingRequest: ToolCall | null` — 当前等待审批的请求
  - `config: PermissionConfig` — 按工具类型的审批策略
  - `resolve(decision)` — 发送审批结果
  - `updateConfig(tool, mode)` — 更新策略
  - 配置持久化到 SQLite
- [ ] **T3.5** Auto-accept 逻辑
  - 配置为 `always` 的工具 → 自动批准，不弹窗
  - 配置为 `always` + 勾选 "session only" → 当次会话有效
  - 输入框下方显示快捷 Auto-accept 开关

#### Day 5.5（半天）
- [ ] **T3.6** 审批流程联调
  - CC 输出 Write tool_use → Rust 暂停 → 前端弹 diff → 用户 Approve → CC 继续
  - CC 输出 Bash tool_use → 弹命令预览 → 用户 Reject → CC 跳过
  - Edit & Approve → 修改内容后 CC 使用修改后的内容
  - Auto-accept 配置生效验证
  - 多个工具调用排队处理

### 验收标准
- [ ] Write 文件时弹出 diff 预览，Approve 后文件被写入
- [ ] Reject 后 CC 跳过该操作继续执行
- [ ] Edit & Approve 修改内容生效
- [ ] Auto-accept 配置正确（always 直接通过，ask 弹窗，deny 拒绝）
- [ ] 多个工具调用按顺序排队审批

## Phase 4：会话 + @引用 + /命令（1.5 天）

### 目标
完善会话管理、文件引用、斜杠命令。

### 任务清单

#### Day 6
- [ ] **T4.1** SQLite messages 表
  - 字段：id, session_id, role, content, tool_calls(JSON), token_usage(JSON), duration_ms, timestamp
  - 插入/查询/删除操作
- [ ] **T4.2** useSessionStore（Zustand）
  - Session CRUD（create/rename/delete/switch）
  - 按项目 + 时间分组
  - 会话标题自动从首条用户消息提取
  - 当前活跃会话高亮
- [ ] **T4.3** Sidebar 会话列表
  - 分组显示：项目名 → 会话列表
  - 🔥 标记当前会话
  - 右键菜单：重命名、删除、📌 固定
  - 搜索过滤（标题 + 内容）
- [ ] **T4.4** 会话持久化
  - 切换会话 → 保存当前消息 → 加载目标会话消息
  - 启动应用 → 恢复上次会话
  - 消息分页加载（最近 100 条，上拉加载更多）
- [ ] **T4.5** FileAtMention 组件
  - 输入框 `@` 触发文件补全
  - Rust 端扫描项目目录结构
  - 前端 debounce 300ms 过滤
  - 选中后高亮 `@path` 标签
  - 发送时后端替换为文件内容（`<<FILE:path>>...<<END_FILE>>`）
- [ ] **T4.6** SlashCommands 组件
  - 输入框 `/` 触发命令菜单
  - 支持命令：`/clear` `/model` `/compact` `/help` `/config` `/cost`
  - 命令自动补全 + 说明

#### Day 6.5（半天）
- [ ] **T4.7** TokenBar 组件
  - 从 CC result 事件获取 token usage
  - 进度条 + 百分比文字
  - 变色：< 70% 蓝 / 70-90% 黄 / > 90% 红
  - > 90% 显示警告
- [ ] **T4.8** 消息编辑 + 重新生成
  - 用户消息 ✏️ 按钮 → inline textarea 编辑
  - Resubmit → 删除该消息及后续 → 重新发送
- [ ] **T4.9** 对话压缩（Compact）
  - `/compact` 命令 → 发送特殊指令给 CC
  - CC 返回摘要 → 替换旧消息
  - 重置 TokenBar

### 验收标准
- [ ] 新建会话 → 输入消息 → 切换会话 → 切回消息不丢
- [ ] 重启应用后消息恢复
- [ ] `@` 文件引用补全正常，发送后 CC 能读取文件内容
- [ ] `/clear` 清空、`/model` 切换模型生效
- [ ] TokenBar 百分比和变色正确
