**日期**: 2026-03-15  
**版本**: v1.0（需求讨论整理）

## 一、系统定位

| 项目 | 说明 |
|------|------|
| **产品形态** | 个人工具 + 轻量 SaaS 服务 |
| **目标用户** | 有 AI Agent 编排需求的开发者 |
| **核心场景** | 通过 OpenClaw 指挥 CC、Codex、OpenCode 等编程 Agent，打造 AI 开发团队 |
| **暂不涉及** | 商业化、付费、计费 |
| **远期可能** | 企业业务支持（预研中） |

---

## 二、系统架构总览

### 前台（用户使用）
- **Dashboard** — 总览页，系统状态一览
- **Agent 管理** — Agent 实例管理（列表、状态、启停、日志）
- **任务中心** — Project → Task → Job 三层任务管理
- **Gateway 监控** — Bridge 连接状态、消息流、任务路由

### 后台（管理员配置）
- **用户管理** — 注册、登录、权限分配
- **Agent 类型配置** — 类型模板（连接方式、参数结构、能力范围）
- **工作流编辑器** — 可视化拖拽编排、模板库管理
- **Gateway 配置** — 连接参数、路由策略、限制规则
- **系统设置** — API Keys、模型参数、Rate Limit、通知通道等
- **心跳/定时任务** — 创建、配置、管理

## 三、功能模块详细需求

### 3.1 用户体系

| 功能 | 说明 |
|------|------|
| 注册/登录 | 邮箱+密码，短信可选 |
| 用户角色 | 系统管理员 + 普通用户 |
| 多租户隔离 | 每个用户的数据（Agent、任务、工作流、配置）互不可见 |
| 配额管理 | 每用户可配置：最大 Agent 数、最大任务数、API 调用次数等 |
| 个人设置 | 通知偏好、默认模型等 |

**权限模型：**
```
Admin（系统管理员）
  └── 全部权限 + 后台管理入口
Viewer（只读用户）— 未来扩展
User（普通用户）
  └── 前台功能 + 自己的数据
```

---

### 3.2 Agent 管理

**概念拆分：类型（模板）+ 实例**

#### 后台：Agent 类型配置

| 配置项 | 说明 |
|--------|------|
| 类型名称 | 如：cc, codex, opencode, openclaw-agent |
| 连接协议 | SSH / WebSocket / 本地进程 |
| 连接参数模板 | 连接时需要的参数结构定义（如 host, port, token） |
| 默认模型建议 | 常用模型列表（用户可在此基础上修改） |
| 能力标签 | 该类型 Agent 支持的能力（如：code-review, test, deploy） |
| Adapter 实现 | 后端需要为每个类型实现对应的连接适配器 |
| 可维护 | 支持动态注册新类型 |

#### 前台：Agent 实例管理

| 功能 | 说明 |
|------|------|
| 实例列表 | 显示所有 Agent 实例及状态 |
| 创建实例 | 选择类型 → 填连接参数 → 测试连通 → 入库 |
| 在线/离线状态 | 实时 WebSocket 推送 |
| Sub-agent 展示 | 主 Agent 下挂载的子 Agent 列表（如 CC 的 programmer/reviewer/tester） |
| Sub-agent 状态 | 每个 sub-agent 当前在执行什么任务 |
| 启停控制 | 启动/停止 Agent 实例 |
| 日志查看 | Agent 执行日志实时展示 |
| 双向追溯 | 点 Agent → 看它在执行的任务；点任务 → 看谁在执行 |

**模型选择：**
- 手动输入（灵活）
- 最近使用记录（便捷）
- 后台配置的常用模型列表（引导）

### 3.3 任务中心

**三层结构：Project → Task → Job**

```
Project（项目）
├── 名称、描述、创建时间
├── 关联的工作流模板
├── Spec 约束（项目的整体规范）
└── Task（任务）
      ├── 名称、描述、状态、优先级
      ├── 执行者（Agent 实例）
      ├── 进度（Job 完成比例）
      ├── Spec 约束（任务级规范）
      └── Job（执行项）
            ├── 分配给具体 Agent/sub-agent
            ├── 状态（pending/running/completed/failed/waiting_approval）
            ├── 输入/输出/日志
            ├── 重试机制（失败自动/手动重试）
            └── 超时设置
```

#### Project 层
| 功能 | 说明 |
|------|------|
| 项目列表 | 所有项目概览 |
| 创建项目 | 名称、描述、关联工作流模板 |
| 项目进度 | 总体完成度、当前阶段 |
| 项目 Spec | 项目级规范约束（Markdown/YAML） |
| 成本统计 | 该项目消耗的 Token、费用 |

#### Task 层
| 功能 | 说明 |
|------|------|
| 任务列表 | 按项目分组，支持状态过滤、搜索 |
| 任务详情 | 状态、执行者、进度、时间线 |
| Spec 约束 | 任务级规范（在 prompt 上下文中传递给 Agent） |
| 依赖关系 | Task 之间的执行依赖（串行/并行） |
| 等待确认 | 需要用户介入的节点高亮提示 |
| 时间线 | 任务执行过程的可视化时间线 |

#### Job 层
| 功能 | 说明 |
|------|------|
| Job 详情 | 分配的 Agent、执行状态、输入输出 |
| 实时日志 | Agent 执行日志实时推送 |
| 重试 | 失败后重试（配置重试次数和间隔） |
| 超时 | 超时自动标记失败/通知用户 |
| Spec 验证 | 执行完成后验证输出是否满足 Spec |

#### Spec 编程支持
- 在 Project 或 Task 中创建 Spec 约束
- Spec 以 Markdown/YAML 格式存储
- 作为上下文注入 Agent prompt
- 未来支持自动验证（深度集成 OpenSpec）

### 3.4 工作流引擎

**定位：编排系统内置调度，不依赖特定 Agent 框架**

#### 后台：工作流管理

| 功能 | 说明 |
|------|------|
| 可视化编辑器 | 拖拽节点、连线、配置属性（类似 n8n/Retool） |
| 节点类型 | 任务执行、条件分支、并行执行、人工审批、通知、等待、Lobster 调用 |
| 模板库 | 系统预置 + 用户自建 + 多用户共享 |
| 版本管理 | 工作流模板的版本历史 |
| JSON 存储 | 底层 JSON 格式，前端可视化交互 |

#### 工作流节点类型
| 节点 | 说明 |
|------|------|
| **Start** | 流程入口 |
| **End** | 流程出口（成功/失败） |
| **Task** | 分配 Job 给 Agent 执行 |
| **Condition** | 条件分支（根据上一节点输出决定走哪条线） |
| **Parallel** | 并行执行多条分支 |
| **Approval** | 暂停等待用户确认（可配置通知渠道） |
| **Notify** | 发送通知（飞书/钉钉/Slack/Discord） |
| **Wait** | 等待指定时间或条件 |
| **Lobster** | 调用 Lobster 工作流（作为节点类型之一） |
| **Script** | 执行自定义脚本（可选，后期） |

#### 前台：工作流引用
- 创建任务时选择工作流模板
- 查看工作流执行状态
- 可视化展示当前执行到哪个节点

### 3.5 Gateway

#### 后台：Gateway 配置
| 配置项 | 说明 |
|--------|------|
| 连接参数 | WS 端口、超时时间、心跳间隔 |
| 路由策略 | 最少负载 / 轮询 / 指定 Agent |
| 连接限制 | 最大连接数、单 IP 限制 |
| Rate Limit | 按端点配置请求频率限制 |
| 消息协议 | 消息格式定义和验证 |

#### 前台：Gateway 监控
| 功能 | 说明 |
|------|------|
| Bridge 列表 | 所有注册的 Bridge 及连接状态 |
| 实时状态 | 在线/离线/忙碌 |
| 消息流 | 实时展示消息收发（可过滤） |
| 任务路由 | 当前任务分配给哪个 Bridge |
| 强制操作 | 断开 Bridge、取消任务 |
| 历史统计 | 连接数趋势、消息量、错误率 |
