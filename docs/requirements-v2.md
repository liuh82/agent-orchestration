# Nexus V2 需求规格书

> 2026-03-15 综合讨论整理，目标是功能完善的终版系统

---

## 一、整体架构

### 前台（用户主界面）
- **Dashboard** — 全局概览、成本统计、待处理提醒
- **项目中心** — 项目的 CRUD + 文档管理，任务创建/配置/启动
- **任务中心** — 全局监控视图，三层级展开（项目→任务→Agent执行明细）
- **工作流** — 工作流定义、模板库（后续迭代）
- **设置** — 个人配置

### 后台（管理界面，浅色主题）
- **Gateway 管理** — Bridge 列表、连接/断开
- **代理中心** — Agent CRUD、Agent 类型管理
- **用户管理** — 用户列表、角色权限
- **系统设置** — 全局配置
- **通知配置** — 通知渠道管理
- **全局统计** — 跨用户维度的统计数据

## 二、项目中心

### 2.1 项目 CRUD
- 创建/编辑/归档/删除项目
- 项目基本信息：名称、描述、状态（活跃/归档）

### 2.2 项目文档库
项目创建时配置以下文档，所有文档支持在线编辑（Markdown 编辑器）和文件上传：

| 文档类型 | 用途 | 说明 |
|---------|------|------|
| 项目概述 | 目标、背景、范围 | Markdown |
| 架构设计 | 系统架构、模块关系、技术选型 | Markdown + 图片(PNG/SVG) |
| 规范约束 | 编码规范、命名规则、安全要求 | Markdown |
| 依赖说明 | 技术栈、版本要求、第三方服务 | Markdown |

支持格式：`.md` `.txt` `.json` `.yaml` `.py` `.ts` `.tsx` `.js` `.pdf` `.png` `.jpg` `.svg`

### 2.3 项目内任务管理
- 在项目详情页内创建/编辑/删除任务
- 任务绑定 Agent 和 Workflow
- 任务附加文件（Prompt、输入文件、参考文件）
- 启动/暂停/恢复/取消任务
- 启动后自动推送到任务中心，并跳转到任务中心查看
- 项目级别状态汇总（运行中/排队/完成/失败）

### 2.4 Agent 配置文件
绑定 Agent 到项目时，系统根据 Agent 类型提供对应的配置文件模板：

| Agent 类型 | 必要文件 | 说明 |
|-----------|---------|------|
| Claude Code | `CLAUDE.md` | 项目指令、工具使用偏好、约束规则 |
| Codex | `AGENTS.md` + `codex.md` | 任务规范、输出格式、禁止操作 |
| OpenCode | `opencode.json` / `AGENTS.md` | 配置项、模型偏好、上下文 |
| OpenClaw | `SOUL.md` + `MEMORY.md` | 人格设定、记忆上下文 |

用户可编辑这些模板，也可以从项目文档库选择文件覆盖。

### 2.5 任务级文件
创建任务时可附加：
- **Prompt 文件** — 任务具体指令、期望输出格式
- **输入文件** — 需要处理的代码、文档、数据
- **参考文件** — 设计稿、API 文档、历史产出
- **约束文件** — 本次任务的额外限制

Agent 启动时，系统自动打包：项目文档 + 任务文件 + Agent 配置文件 → 作为工作目录上下文传给 Agent。

## 三、任务中心（监控视图）

### 3.1 三层级展示
- **第一层：项目** — 按项目分组展示，每个项目显示任务数量和状态汇总
- **第二层：任务** — 项目下展开任务列表，显示任务名称、状态、绑定的 Agent
- **第三层：Agent 执行明细** — 任务下展开 Agent 的实时执行状态、日志、输出

### 3.2 顶部状态栏
- 全局快速统计：运行中 N / 排队 N / 待处理 N / 今日完成 N / 失败 N
- **待处理徽标**：有任务卡在人工干预节点时，醒目提醒

### 3.3 筛选维度
- 按项目筛选
- 按状态筛选（全部/运行中/排队/等待决策/完成/失败）
- 按 Agent 类型筛选
- 按时间范围筛选

### 3.4 任务详情
点击任务可查看：
- 基本信息（名称、描述、状态、创建时间、Agent、Workflow）
- 执行日志（实时滚动）
- 输入/输出文件列表
- 会话记录（Agent 的对话历史）
- 流程进度（如果绑定了 Workflow）

### 3.5 人工干预交互
当 Workflow 中的任务执行到人工干预节点时：

1. 任务状态变为「等待决策」，顶部状态栏徽标提醒
2. 任务列表中标记突出
3. 点击进入后展示：
   - **流程当前进度**：已完成的步骤 → 当前卡住的节点 → 后续步骤
   - **上下文信息**：前置步骤的输出、Agent 的建议/分析
   - **操作区域**：
     - 文本输入框（输入意见、决策说明）
     - 文件上传（支持审核文档等附件）
     - 操作按钮：批准 / 驳回 / 修改意见后继续
4. 提交后任务自动流转到下一个节点

### 3.6 批量操作
- 支持多选任务
- 批量暂停/取消（跨项目）

### 3.7 创建任务移除
- 任务中心**不再提供创建任务功能**
- 所有创建操作在项目详情页完成

## 七、设计规范

- 前端统一浅色主题（禁止纯黑背景）
- 后台浅色主题（header #334155，content 区 #f5f5f5）
- API 响应格式：`{ code: 0, data: ..., message: "..." }`
- 新增 DB 字段必须 Optional（向后兼容），仅用 Alembic 迁移
